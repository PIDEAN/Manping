# App icon

The 满屏 / Manping icons are original to this project and distributed under its GPL-3.0 license.
The app icon is an Icon Composer document (`Resources/AppIcon/AppIcon.icon`: four layered, glass-material
streaks on a dark gradient, no external artwork), generated by `scripts/make_app_icon.py`. Release bundles
compile it with `actool` into `Assets.car` and `AppIcon.icns`; the script also exports the flat
`AppIcon.png`/`AppIcon.icns`, the Debug variant `AppIconDebug` (with a DEBUG badge, composed by
`scripts/render_app_icon.swift`), the sidebar mark `StoreLogo.png` and the menu bar template
`MenuBarIcon.png` (three solid streaks drawn by the same script; Sources/ManpingApp/Resources).
Earlier private builds used the upstream Bili.Copilot logo; it is no longer part of this repository.
