待用户在场时，使用一个最终构建集中执行只读验收：

1. 使用者处理该签名的防火墙软件放行；若登录过期，由使用者扫码。脚本不处理安全弹窗。
2. 运行 `scripts/live_check.sh --wait 60 --video BV1xx411c7mD --pgc ep837204`；实网截图只存 `.build/live-private/`，不提交。默认列表已含专栏推荐／排行、四类消息、下载和设置。
3. 复验推荐播放文字、索引首屏、时间线停更文案、其它搜索类型／榜单／分区／收藏内容、M6阅读与消息、真实下载恢复和外置磁盘错误。
4. 检查PGC互动只读状态、空间资料弹出卡、评论/动态inline表情，以及清晰度／编码、弹幕样式／长按倍速、精确跳转、字幕AI过滤、章节、截图、缓存、独占音频、自定义 libmpv/profile，以及独立窗口关闭恢复与外部 mpv 退出。
5. 检查系统媒体键、封面／进度和通知授权／动态轮询／换号清理；AI 凭据在本地凭据目录的保存、读取和删除，以及从 0.1.2 升级时的一次性迁移。开发验收不调用付费 AI。
6. 检查最终 Release 使用者启动、物理 HDR／外屏、睡眠恢复及长期播放。全部账号写操作仍只在 fixture 中自动测试。

本轮性能未达项及原因按 Performance 实测结论保留，不放宽60fps或4K60掉帧阈值。
