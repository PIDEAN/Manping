# 满屏设计系统：流光玻璃（2026-10-18）

设计稿：「满屏 Manping 品牌与界面设计」画布（品牌总览、图标、信息架构、首页、视频页、播放控件、小窗、直播间、设置窗口、组件、文案）。代码实现在 `Sources/ManpingApp/Theme.swift`（令牌与通用样式）和 `Sources/ManpingApp/DesignComponents.swift`（共享组件）。本文是实现的唯一依据；与旧代码冲突时以本文为准。

## 1. 品牌
- 名称：中文「满屏」在前，英文「Manping」只用于关于页、README 和对外场合。
- 基调：内容为先、流光为记、原生材质。界面用冷调墨色退后；彩色只来自封面、视频和弹幕；控件只用一个强调色。
- 品牌图形「流光」：头圆尾细、向左渐隐的流线（一条被抽象的弹幕）。只出现在：应用图标、菜单栏图标、弹幕开关符号、进度条已播放段、加载动画。不做别的装饰。
- 标志：侧边栏顶部「图标 24 pt + 满屏（15 粗，字距 +2）」，全应用只出现这一次。

## 2. 图标
- 交付格式：Icon Composer `.icon`（`Resources/AppIcon/AppIcon.icon`），由 `scripts/make_app_icon.py` 生成：4 层液态玻璃流线（雾白 #F6F3EE、流光青 #2EC0F7、弹幕粉 #FF4F95、琥珀 #FFB13B），背景墨蓝竖向渐变 display-p3 (0.15,0.18,0.28) → (0.04,0.05,0.09)，无内框。
- 打包：`actool` 把 `.icon` 编译成 `Assets.car`（系统按默认 / 深色 / 透明 / 着色渲染），同时生成 `AppIcon.icns` 作回退；`CFBundleIconName = AppIcon`。Debug 版在导出的 PNG 上加 DEBUG 角标，只用 `.icns`。
- 菜单栏图标：三条实心流线的模板图（18 pt，`MenuBarIcon.png` @2x 36 px），同一图形是播放器「弹幕开关」的符号（`DanmakuSymbol`）。
- `StoreLogo.png`（128 px）由 `.icon` 的默认外观导出。

## 4. 材质
- 液态玻璃（SwiftUI `glassEffect` / `.buttonStyle(.glass)` / `.glassProminent`，多个相邻玻璃控件包在 `GlassEffectContainer` 里）只用于浮在内容之上的东西：侧边栏、工具栏控件组（返回/前进、分段、搜索、刷新）、播放控件面板、弹出面板与菜单、小窗控件、下一个提示。
- 实色表面：卡片、列表、设置分组、评论区。滚动内容里不放玻璃。
- 播放控件面板是玻璃，但只在显示时存在（自动隐藏），显隐不改变画面尺寸。
- 阴影只在悬停态出现，不挂在滚动内容的常驻状态上。

## 6. 圆角与间距
- 圆角四档 + 胶囊：`xs` 6（角标）、`sm` 10（列表行、输入框、菜单项）、`md` 14（封面、卡片、播放控件面板）、`lg` 20（面板、弹出面板、播放舞台）；按钮、标签、分段一律胶囊。嵌套用同心圆角。不再用 4、5、8、12、13、15、16 等散值（小窗外框 16 例外，跟随系统窗口）。
- 间距 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。页面边距 24，网格间距 20（列）/ 24（行），封面与标题 10。
- 控件高度：28（小）、32（常规）、36（工具栏）、40（播放主按钮）。

## 7. 主窗口与信息架构
- 窗口：全尺寸内容、隐藏标题，红绿灯在侧边栏玻璃内左上角。最小 900 × 600。
- 侧边栏（232 pt，玻璃，可 ⌃⌘S 隐藏；窗口宽 < 1000 时收成 68 pt 图标栏）：
  - 标志行。
  - 「发现」：首页 ⌘1（原流行：推荐 / 热门 / 排行榜，分段放工具栏）、分区 ⌘2（原视频）、直播 ⌘3、番剧 ⌘4（原动漫）、影视 ⌘5、专栏 ⌘6（原文章）。
  - 「我的」：动态 ⌥⌘1、收藏 ⌥⌘2、稍后再看 ⌥⌘3、历史记录 ⌥⌘4、下载 ⌥⌘5、消息 ⌥⌘6（未读数用 `live` 胶囊）。
  - 底部账号行：头像 + 名字 + 等级；点击弹出：我的空间、我的关注、我的粉丝、固定的 UP 主与直播间、退出登录。
  - 每项可在 设置 › 通用 › 侧边栏 中隐藏。
- 工具栏（内容区顶部 60 pt）：返回 / 前进（玻璃组）、页面标题、页面内分段（如有）、弹性空白、搜索框（300 pt 玻璃，占位「搜索视频、番剧或 UP 主」，⌘F；热搜 ⌘K）、刷新。原顶部收藏 / 稍后再看 / 历史快捷组及其设置项取消。
- 二级导航（分区列表、收藏夹列表、消息会话、专栏分区等）仍为内容区左侧 232 pt 列，实色 `panel` 底。
- 设置不再是主窗口页面，改为独立的设置窗口（SwiftUI `Settings` 场景，⌘,），见第 10 节。
- 播放页（视频、番剧、直播间）：进入时侧边栏自动滑走，画面和右侧栏占满内容区；离开播放页恢复原来的显示状态。播放页上按 ⌃⌘S 时侧边栏以浮层盖在页面上方，点击别处或离开播放页时收起，不改变保存的显示 / 隐藏偏好。

### 顶栏动作
页面通过 `.pageToolbar(accessory:)` 放进顶栏的控件只有三种形态，都是 36 pt 玻璃，与返回 / 前进、刷新同高；顶栏不出现纯文字链接按钮。
- 带文字的动作（我的追番、播放精选、多选、关注的直播间、进入 UP 主空间……）：玻璃胶囊，图标 + 文字，前景主色（`toolbarActionStyle()`；危险动作用 `.destructive`）。
- 单个图标动作（侧栏开关、停止加载、关注）：36 玻璃圆（`toolbarIconStyle()` + `ToolbarIcon`），与刷新相同。
- 相邻的多个图标动作合成一个胶囊组（`ToolbarIconGroup`，每格 32 pt，`ToolbarGroupIcon`），每格都有 `.help` 名称；如视频页的 分享 / 独立窗口 / 侧栏开关。与带文字的动作相邻时各自独立。
- 顶栏里的菜单用 `appMenuStyle(toolbar: true)`，输入框高 36。

### 二级栏图标规则
固定入口（时间线、番剧索引、我的追番 / 我的追剧、私信、推荐直播等）带图标；数据列表（直播分区、更新日、会话、搜索范围、收藏夹、关注分组）不带图标。有计数的行把计数放右侧。

## 10. 设置窗口
- SwiftUI `Settings` 场景，760 × 560 起，左侧玻璃侧栏 9 个分类，右侧 `Form(.grouped)`。
- 通用（外观、侧边栏项目、搜索建议、滚动加速、图片缓存）· 播放（画质与编码、进度与倍速、连续播放、打开方式、番剧）· 弹幕（外观、屏蔽、默认显示）· 网络（节点优选、缓冲、代理）· 下载与截图 · 通知（系统通知、开播提醒、菜单栏图标、Dock 角标）· 隐私（同步观看进度、聚焦搜索与接力、暂停时识别画面文字）· AI · 高级（播放引擎 mpv、画面增强、缓存、日志）。
- 移除 4 个 Windows 专属项；「关于」移到 满屏 › 关于满屏（标准关于面板，含致谢链接）。
- 「使用集成播放器」「默认播放显示模式」合并为「打开视频时：在主窗口 / 全屏 / 小窗 / 独立窗口」。

## 11. 播放器
- 控件是舞台底部内缩 12 pt 的玻璃面板（`md` 圆角）：第一行进度条，第二行左组「播放（40，mist 底）· 下一个 · 时间 · 弹幕开关（DanmakuSymbol，开启时 accent 底）· 弹幕输入框（胶囊，占位「发一条友善的弹幕」）」，右组默认「画质 · 倍速 · 字幕 · 音量 · 小窗 · 全屏」，最右「更多」（见下文「控制条自定义」）。
- 进度条：轨道白 22%，缓冲白 32%，已播放段为流光（青，尾部 25% → 头部 100%），拇指白色 14 pt + 青色 4 pt 光环；上方 14 pt 高能曲线（`highlight`，竖向渐隐，弹幕 ≥ 20 条才画）；章节刻度 2 × 8 pt 白线；悬停预览 176 pt 缩略图 + 「时间 · 章节名」。
- 显隐：鼠标移入、按播放快捷键、暂停时显示；鼠标静止 2.5 秒且不在控件上则隐藏（全屏时同时隐藏指针）；打开面板、输入弹幕、拖动、暂停时保持显示。淡入 0.18 秒、淡出 0.3 秒并下移 6 pt；「减弱动态效果」时只淡入淡出。隐藏后底边 3 pt 流光进度（设置可关）。
- 窄宽度时按「控制条自定义」的收起规则收进「更多」。
- 弹出面板（画质、倍速、弹幕、音量、「更多」菜单）一律玻璃。倍速：0.5、0.75、1.0、1.25、1.5、2.0、3.0。
- 页头：返回、标题、分享、在独立窗口播放、显示 / 隐藏右侧栏。右侧栏 372 pt，分段「简介 / 评论 N / 分集 N / 相关 / AI」，操作按钮「点赞 / 投币 / 收藏 / 三连」为玻璃方块。
- 直播：同一面板，无进度条；左组「播放 · 重新连接 · 弹幕开关 · 已开播 h:mm:ss」，右组「线路胶囊（绿点 + 线路 N · 编码）· 画质 · 音量 · 设置 · 小窗 · 全屏」。标题前「直播中」徽标。右侧栏分段「弹幕 / 主播」。
- 舞台：视频页、番剧页和直播间把画面放在一个圆角舞台里。舞台 `lg` 圆角、0.5 pt 边线（深色白 6%、浅色黑 8%），离窗口边、工具栏和右侧栏各 12 pt，底色近黑 `stage`（#05070B），深浅色外观相同。全屏时去掉圆角、边距和边线。
  - 氛围色：画面按视频比例居中，四周是封面放大、模糊、饱和度 × 1.25、亮度 × 0.35 的静态图，向舞台边缘加深，代替黑边。一张封面只算一次，不从视频取样。没有封面，或低电量模式、机身严重发热且开启了「进一步省电」时，降级为纯 `stage` 色。
  - 弹幕铺满舞台：弹幕层与舞台内容区同尺寸（主窗口、独立窗口、全屏都一样），会飘过画面四周的氛围色；四分之一 / 半屏 / 全屏的显示区域按舞台高度计算。画面比例以播放器报告的实际尺寸为准，清单里的尺寸（直播间假定 16:9）只在报告前使用。长按临时倍速等手势在整个舞台内有效。小窗不变（见第 12 节）。
  - 控制面板在舞台内内缩 12 pt，`md` 圆角，被舞台圆角裁切；隐藏后的 3 pt 流光进度同样被裁切。
  - 右侧栏是 `panel` 实色圆角面板（`lg`，0.5 pt `separator` 边线），宽 372 pt，窄窗口时不超过可用宽度的 40%。分段放不下时从右往左收进末尾「…」菜单，当前分段始终可见，AI 不会因为窄而消失。

### 控制条自定义
- 固定区：左组「播放 · 下一个 · 时间 · 弹幕开关 · 弹幕输入框」和最右侧「更多」不可移动、不可移除。
- 可自定义区：右组，可选 13 项（画质、倍速、字幕、音量、弹幕设置、截取画面、网络与节点、画面增强、只听声音、下载、小窗、独立窗口、全屏），默认「画质 · 倍速 · 字幕 · 音量 · 小窗 · 全屏」。在 设置 › 控制条 中拖动编辑：拖到两项之间插入，拖到某项上替换，拖出控制条移除；键盘与右键菜单有「左移 / 右移 / 添加到控制条 / 移除」。直播间跳过不支持的项。
- 收起规则：宽度不够时先把弹幕输入框缩成「发弹幕」按钮，再从右组最左边一项开始依次收进「更多」，最右边的项留得最久。「更多」右上角显示已收起的项数。
- 「更多」菜单三段：已收起的项（保留各自的子菜单）— 不在控制条上的其他功能 — 「自定义控制条…」（打开 设置 › 控制条）。

### AI 面板
- 位置：视频页和番剧页右侧栏的「AI」分段、专栏的 AI 助手侧栏。顶部是模型菜单、「上下文：…」胶囊（点开为上下文弹层）和「…」（导出、清空）；下面是预设胶囊，然后是对话；底部是追问输入框（`fill` 底、`md` 圆角，与回答卡片同样离面板边 16 pt，附带「当前进度」胶囊）。
- 预设：视频与番剧「只看 3 分钟 · 章节总结 · 高能时刻 · 弹幕在聊什么 · 评论区观点 · 评价」，加上追问；专栏「专栏要点 · 评论区观点 · 专栏评价」。自定义预设排在内置预设后面。
- 上下文弹层：按层列出本次要发送的内容（字幕、官方章节、弹幕、评论、当前进度等）、估算长度与模型窗口、字幕语言顺序。这里的开关只对本次有效；超长时说明会按章节分段整理。
- 卡片类型：章节、高能时刻、片段（只看 3 分钟）、评论区观点、Markdown 正文（列表、代码、表格、引用）、官方总结回退。每张卡片底部「依据：…」与「模型 · 已保存 · 时间」，操作「拷贝 / 重新生成」。
- 时间戳与进度条刻度：卡片里的时间是可点的胶囊，点击跳到当前播放器的该时刻；当前显示的回答在进度条上用 `highlight` 琥珀色刻度标出对应时刻。
- 片段依次播放：「依次播放」按顺序播放片段，片段之间自动跳转；播放期间暂停连续播放和自动跳过片头片尾；用户拖动进度条、按 ← / →、选章节，或换了视频、分 P、剧集时退出；最后一段结束后暂停。
- 隐私开关优先：设置 › AI 中关闭发送的内容，任何预设都不会发送。预设需要它时胶囊标明「需要「X」：已在 设置 › AI 中关闭发送」，并提供「仅本次发送「X」并生成」，只对这一次生效。

### 省电策略
- 空闲弹幕不刷新：屏幕上没有弹幕且已经画过一帧空白时，弹幕层不再清屏和提交，刷新降到 10 Hz，直到 0.35 秒内有弹幕要出现；时钟、分道和位置不变。
- SDR 不走 EDR：只有 PQ / HLG 片源使用 EDR 输出；SDR 片源按 SDR 屏幕的方式输出 BT.709 / sRGB，使用 8 位图层。
- 以上两项一直开启，不受设置控制。其余省电项由用户决定，见 设置 › 播放 › 省电（排在「进度与倍速」之后）。
- 省电模式：「自动（用电池或机身发热时）」（默认）、「始终」、「关闭」。有效省电级别：关闭 → 不省电；始终 → 至少轻度省电；自动 → 跟随检测（用电池或机身发热为轻度，低电量模式或机身严重发热为强）。只调整弹幕和画面处理，不影响解码、加载与缓冲。
- 「省电时弹幕最高 60 帧」（默认开）：省电时弹幕层最高 60 帧。弹幕帧率（设置 › 弹幕 › 外观）选「60 帧」时总是最高 60 帧。
- 「低电量模式或严重发热时进一步省电」（默认开）：强省电时屏幕上最多 40 行弹幕，舞台氛围色降级为纯色。
- 「省电时降低画面处理质量」（默认关）：省电时新建的播放引擎用 mpv 的 fast 配置，下一个视频起生效。画质配置（设置 › 高级）只有「高质量」（默认）和「高性能」；「高性能」总是用 fast，旧版本保存的「自动」按「高质量」读取。
- 状态：设置分组末尾一行说明现在的情况（如「现在：用电池，正在省电。」）；播放器「更多」菜单有「省电模式」子菜单（自动 / 始终 / 关闭、「省电设置…」），正在省电时菜单顶部显示禁用的「正在省电 · 用电池」（或机身发热、低电量模式、始终省电）；弹幕设置面板的省电提示按有效级别和开关显示，点按打开 设置 › 播放。

## 12. 小窗
- 独立的悬浮面板（`NSPanel`，无标题栏，`.floating`，`canJoinAllSpaces` + `fullScreenAuxiliary`，不进 Dock 和 ⌘Tab），主窗口保持原样。
- 锁定视频比例，圆角 16，默认 480 × 270，可缩放 320–960 宽。
- 按住任意处拖动；松手吸附最近屏幕角（距边 16 pt），按住 ⌥ 不吸附。单击暂停 / 继续，双击回到主窗口。
- 悬停：画面压暗 28%，左上「关闭小窗」「回到主窗口」，右上弹幕开关，中间「−10 · 播放 · +10」，底部细进度和时间；1.5 秒无操作淡出。直播：无进度，左上「直播中」。
- 弹幕：字号 × 窗口高度 ÷ 720（最小 13）；显示区域上半部，最多 30 条；不显示弹幕输入框。

## 13. 文案
1. 用 macOS 用语：拷贝、设置、退出、进入全屏幕、在浏览器中打开。
2. 中西文之间加空格（UP 主、1080P 高码率、12.4 万播放）；引号「」；路径 ›。
3. 说明一句话、句号结尾，只说开启后会怎样；按钮和标题不加句号。
4. 内部术语（PGC、shader、IPC、hr-seek、属性名、错误码）只出现在 设置 › 高级 与日志。
5. 状态句式：正在加载 X… / 没能加载 X + 重试 / X 是空的 + 下一步。按钮以动词开头。
6. 全中文；英文只留产品与格式名（ChatGPT、HEVC、AV1、BBDown）。

统一用词：首页（流行）、分区（视频）、番剧（动漫）、专栏（文章）、收藏（收藏夹、我的收藏）、历史记录（观看历史）、下载（下载任务）、上一个 / 下一个（上一集、下一集）、小窗、回到主窗口（返回完整窗口、返回当前窗口）、在独立窗口播放（独立播放窗口）、画质（清晰度）、节点（CDN 地址、线路；直播仍用线路）、画面增强（增强 shader）、截取画面（保存视频截图）、只听声音（仅播放声音）、拷贝（复制）、UP 主（UP主）、直播中（LIVE）。

## 14. 保留的工程约束
- 弹幕渲染：系统字体 Semibold，按屏幕像素 1:1 光栅化；先画 2 pt 描边再盖填充；行高 1.35 倍字号；宽度感知分道；独立渲染线程（CAMetalDisplayLink）+ 锁相时钟。
- 阅读：正文栏最宽 680，16 pt，行高约 1.75，A− / A+（14–22），2 pt 阅读进度（流光）。
- 评论：头像 32，名字 12 半粗，正文 13；置顶与 UP 主用 accent 胶囊；楼中楼原地展开。
- 每个功能至少一个可见入口；播放功能同时在控制条或「更多」菜单，以及菜单栏「播放」中。
- 链接入口：⌘L、拖入链接、`manping://`（video / episode / season / live / article / space）。
