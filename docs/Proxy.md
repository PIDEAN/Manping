# 代理 / VPN（2026-10-18）

## 用途

- **海外观看大陆版权内容**：接口请求经代理发出。出口需要在中国大陆，B 站才会放行地区限制。
- **网络不佳时加速**：经代理隧道访问 CDN 节点。代理线路作为额外的路线加入多 CDN 并发缓冲，与直连线路一起按实测速度分配分段。

## 设计来源

参照作者另一个 macOS 项目里已在真实线路上长期使用的代理实现。

| 参考实现的做法 | 这里的落地 |
| --- | --- |
| 内置 Shadowsocks AEAD 客户端，在本机开一个 SOCKS5 入口 | `ManpingCore/ShadowsocksTunnel.swift`，移植自参考实现的同名文件：chacha20-ietf-poly1305、aes-256-gcm、aes-128-gcm；预热连接池；连续 3 次失败判为不健康并退避探测；本机入口失效后自动重建 |
| 直连与代理是两套 URLSession，按请求决定路由 | `ProxyRuntime` 生成代理会话配置。接口走 `ProxyAuthTransport`，视频分段走带代理的 `CDNURLSessionFetcher` |
| 代理不可用时失败，绝不悄悄走直连 | 隧道没起来时，代理配置指向本机 9 号端口（必定拒绝连接） |
| 草稿设置，点「应用并测试」才生效 | 设置页的代理卡片：编辑不会重启隧道；测试会显示经代理和直连的出口 IP、所在地区，以及出口是否在大陆 |
| 改密码、改加密方式时要让旧状态失效 | `connectionSignature` 包含密码的指纹（不含明文）；只改路由模式不重启隧道 |
| 不照搬：全局关闭证书校验 | 没有照搬，TLS 校验保持系统默认 |
| 不照搬：密码明文存在 UserDefaults | 密码放在钥匙串中和账号同一个条目，不会多出授权弹窗；退出 B 站账号时保留代理密码 |

## 路由

### 接口（大陆版权，设置项「大陆版权内容」）

- **自动**（默认）：先走直连。接口返回地区限制（`-10403`、`6002003`）时，经代理重试一次；成功后 10 分钟内，同类请求直接走代理。涉及的接口有视频详情、普通视频播放地址、番剧详情和番剧播放地址。
- **始终**：所有 B 站接口都走代理。
- **关闭**：不走代理。
- 单个请求的路由用 TaskLocal（`BiliRoute.viaProxy`）传递，不会影响同时进行的其他请求。

### 视频数据（设置项「视频加速」，播放器 CDN 面板里的「代理 / VPN 并发」菜单）

- **卡顿时启用**（默认）：起播只用直连。第一次卡顿时立即把直连节点池里最好的两个节点经代理加入中继，后台测速完成后再换成实测最快的两条代理路线。
- **始终并发**：起播时直连测速和代理测速同时进行，代理路线从一开始就加入节点池。
- **关闭**：视频数据不走代理。
- **中继的路线**：直连节点、经代理的节点，以及经代理访问的接口签发主地址（海外用户可能只能这样访问）。统计按路线键（`host@proxy`）分开记录，调度器按实测吞吐分配分段，慢的路线只会分到很少的分段。
- **门槛**：快速测速经过隧道时，首包往返占了大头，所以代理路线只要能用（≥ 0.5 Mbps）就保留。
- **自动停用与恢复**：代理暂时不可用时，代理路线自动退出节点池；恢复后自动回来。HTTP / SOCKS 代理的健康状态来自实际请求的成败。
- **前提**：需要开启「多 CDN 并发分段缓冲」。mpv 只连本机中继，代理由中继使用。

## 测试

- **单元测试**（`ProxyTests`、`CDNTests`）：
  - EVP_BytesToKey 和 HKDF-SHA1 子密钥：与 Python 独立计算的值逐字节一致。
  - AEAD 分块：三种加密方式都测了跨过 0x3FFF 分块的往返；密码错误时无法解密。
  - 端到端：经内置隧道连到测试用 Shadowsocks 服务端和 HTTP 源站。
    - 8 MB 单请求，以及 16 路并发请求，字节完全一致；主机名交给代理端解析。
    - 密码错误或代理服务器宕机时请求失败，源站收不到任何请求（不会改走直连）。
  - 中继：
    - 直连节点全部被拒（模拟地区限制）时，由代理路线交付。
    - 直连和代理速度相同时，两边分担分段。
    - 移除代理后不再有代理请求。
    - 在途计数最后归零。
  - 接口路由：
    - 自动模式先走直连，遇到地区限制再走代理；之后 10 分钟直接走代理。
    - 没有限制的请求保持直连。
    - 始终模式不走直连；关闭模式不走代理。
    - 移除代理后不再走代理。
- **实网测试**：
  - 在测试进程里运行转发型 Shadowsocks 服务端（`ProxyLiveTests`，需设置 `MANPING_LIVE_PROXY=1`），经内置隧道访问真实的 B 站接口。
  - Debug 版在「接口始终走代理 + 视频始终并发」下播放真实视频：起播正常，代理路线和直连同时取数据，0 卡顿。
  - 「卡顿时启用」：模拟卡顿后立即启用代理路线，测速完成后换成实测最快的线路。
  - 新编译的独立二进制首次联网会被防火墙软件拦截。测试用的转发服务端因此放在已被放行的测试进程里运行。

## 尚未验证

- **区域解锁本身**：需要出口在中国大陆的真实代理（例如出口在中国大陆的 Shadowsocks 服务器）。测试会显示出口所在地；使用者在设置里填好并点「应用并测试」后，用大陆限定的番剧复验。
- **HTTP / SOCKS5 代理**：只验证了配置生成，没有用真实服务器测试。
